# Baton — 按鍵

[English](KEYS.md) · **繁體中文**

完整的按鍵參考。[SPEC.zh-TW.md](./SPEC.zh-TW.md) 說明各種畫面與背後的模型,本文件只談你怎麼操作它們。
在任何畫面按 `?` 可看該畫面的即時清單,按 `C-t k` 可重新綁定這裡的任何一項。

## 模型

決定一次按鍵意義的有三件事:你所在的模式、動作是否需要領導鍵,以及它是否掛在中繼鍵底下。

### 分模式

在儀表板裡,按鍵屬於 baton,所以動作在裸鍵上觸發。在放大或互動格裡,按鍵屬於你正在操作的程式,所以一個
baton 動作是領導鍵 `C-t` 再接同一個鍵。其餘不變——你在儀表板學會的鍵,在放大裡就是同一個鍵,前面多按一個
`C-t`。

群組分割介於兩者之間。它自己的鍵是裸鍵(`tab`、`L`、`z`、`p`、`i`、`x`、`s`、`S`),與儀表板共用的少數指令
也是,但下面那幾組中繼鍵家族在那裡還不能用——按 `C-t d` 回儀表板,或按 `?` 看分割畫面實際有哪些鍵。

```text
儀表板      p              開一個 shell 面板
放大        C-t p          開一個 shell 面板
```

### 領導鍵

`C-t` 是領導鍵。少數動作只能透過它觸達,在每個畫面裡都是,儀表板也不例外——要嘛因為它們的裸鍵屬於導覽
(`k` 是上,`l` 是右),要嘛因為它們的後果太大,不該放在離方向鍵一個指尖的地方(`C-t S` 會結束整個 fleet)。
這些就是逃脫鍵,在下表中標記為 `C-t`。

在放大裡,`C-t C-t` 會送出一個字面的 `C-t` 給程式。

### 中繼鍵

有四個鍵是中繼鍵:它們自己不做任何事,只打開一組相關的動作。

| 中繼鍵 | 家族                                     |
| ------ | ---------------------------------------- |
| `n`    | **n**ew——`p` 與 `A` 之外的其他開啟方式   |
| `v`    | **v**iew——座艙怎麼畫,而不是 fleet 做什麼 |
| `g`    | **g**roup——工作項目的一切                |
| `x`    | 破壞性動作——連按兩下,第二下就是確認      |

按下中繼鍵後,狀態列會列出它接下來能收哪些鍵,所以一個家族是按出來的,不是從這一頁讀出來的:

```text
 DASHBOARD │ g …  g mark · c create · a add · u ungroup            ⏱ 09:34:51  ● attached · local
```

沒有任何中繼鍵同時是一個獨立動作,所以一個完整的序列在你按下最後一鍵的當下就觸發。不等待,也不會有歧義。

### 逾時

懸空的中繼鍵會失效,連同狀態列上的提示一起清掉。預設是 `1.2s`:

```yaml
# $HOME/.baton/config
settings:
  key-timeout: 1.2s # 中繼鍵等待下一鍵的時間;0 = 永不失效
```

`0` 關閉逾時,中繼鍵(含領導鍵)會無限等待——也就是這個設定出現之前 baton 的行為。落在 `200ms`–`10s` 之外的
值會回落到預設。

同一個逾時也用來解決有歧義的綁定——某個鍵同時是另一個較長綁定的開頭,就像 vim 裡 `d` 與 `dd` 的關係。
預設按鍵表沒有這種情況,所以只有你自己綁出一個時才會遇到,而 `C-t k` 會在你這麼做時提醒你。

## 全部按鍵

領導鍵欄:`C-t` 表示每個畫面都需要;`(C-t)` 表示只有放大需要;`·` 表示不需要。
中繼鍵欄:如果動作掛在某個中繼鍵底下,這裡是你要先按的那個鍵。中繼鍵在儀表板可用,在放大裡加領導鍵也可用;
群組分割有自己的一套鍵,觸達不到它們。標記 `(C-t)` 但需要儀表板某一列的動作(工作項目那幾個動詞),在放大裡

## 重新綁定

`C-t k` 可即時編輯按鍵對應並寫進 `$HOME/.baton/config`。在某一列按 `e` 開始收鍵,按 `enter` 才真正綁定,`esc`
放棄——因為一個綁定可能不只一個鍵,沒有別的方式能說清楚這串鍵在哪裡結束。只有你改動過的部分會被寫入,所以
往後預設值若有調整,會直接傳到你這裡,而不是被一份過期的副本蓋住:

```yaml
# $HOME/.baton/config
prefix: ctrl+t # 領導鍵
keys:
  new-agent: "F2" # 單一鍵
  ungroup: "g d" # 序列:token 之間用空白分隔
  purge-exited: "x" # 如果你偏好,把連按兩下收回成一鍵也可以
settings:
  key-timeout: 1.2s
```

一個綁定是以空白分隔的按鍵序列。`space` 是空白鍵的 token,修飾鍵照 bubbletea 的寫法:`ctrl+t`、`shift+left`、
`alt+x`。設定是以綁定的穩定名稱對應,不是以按鍵對應,所以改動其中一個永遠不會動到其他的——而且往後某個預設值
搬家時,也會連同你的自訂鍵一起搬。

若你綁的序列開頭剛好已經是另一個綁定,座艙會在存檔時告訴你:

```text
"add" (a) starts "add-all" (a a) — a waits 1.2s before firing
```

那是警告,不是拒絕。延遲的長度就是 `settings.key-timeout`,而這是唯一會遇到它的情況。

## 從 v1.2 搬過來

底下每一個鍵做的事都和以前一樣,變的只是你怎麼觸達它。你 config 裡重新綁定過的東西完全不用動——綁定是
以名稱儲存的。

| 原本    | 現在    | 為什麼                                                    |
| ------- | ------- | --------------------------------------------------------- |
| `c`     | `n c`   | 開啟家族搬到 `n` 底下,釋出四個字母                        |
| `.`     | `n .`   | 同上                                                      |
| `C`     | `n C`   | 同上                                                      |
| `H`     | `n h`   | 同上                                                      |
| `G`     | `g c`   | 每個工作項目動作現在都以 `g` 開頭                         |
| `a`     | `g a`   | 同上——而且釋出 `a` 之後,收件匣的 `C-t a` 不再被遮蔽       |
| `u`     | `g u`   | 同上                                                      |
| `g`     | `g g`   | 標記仍是這個家族裡最便宜的鍵:同一根手指,按兩下            |
| `U`     | `v u`   | 顯示開關搬到 `v` 底下,再釋出四個字母                      |
| `K`     | `v k`   | 同上                                                      |
| `v`     | `v p`   | 同上                                                      |
| `V`     | `v l`   | 同上                                                      |
| `z`     | `v g`   | 同上——`z` 現在只在分割裡代表調整大小,別處都不是           |
| `x`     | `x x`   | 清掉 fleet 的遺骸要連按兩下,而第二下就是確認              |
| `S`     | `C-t S` | 裸 `S` 在分割裡是對整組送訊號,在儀表板卻是重啟伺服器      |
| `C-t g` | `C-t G` | `C-t g` 現在是領導鍵加上 `g` 中繼鍵,所以 git 選單改用大寫 |

被搬走的那些鍵會再回答一個版本:按下 `U`,狀態列會告訴你它現在住在 `v u`。

## 底下順帶修好的兩件事

- 放大觸達得到每一個逃脫鍵,而指令的解析方式也和儀表板完全相同。過去逃脫鍵在放大裡是手工列舉的,這也是為什麼
  `C-t o`、`C-t c`、`C-t P` 文件上有、按下去卻沒反應;現在它們改由「什麼算是逃脫鍵」的同一張表查出來。指令則走
  和儀表板同一套比對,所以中繼鍵在放大裡也成立(`C-t v u`),用法和放大外一模一樣。至於目標是儀表板某一列的指令
  ——標記、成組、加入——在放大裡沒有東西可作用,它會明說,而不是去動一個你看不見的游標。
- 懸空的領導鍵不會再吃掉你下一次的按鍵。`C-t` 過去會永遠等下去;現在它和其他中繼鍵一樣會失效,而且等待期間
  狀態列會明說。
