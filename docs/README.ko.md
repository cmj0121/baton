AI 코딩 agent를 한 번에 여러 개 돌리고 있나요? 상황은 금방 엉망이 됩니다 — 이리저리 옮겨 다녀야 하는 창들,
탭마다 흩어진 session, 그리고 누가 일하는 중이고 누가 막혔으며 누가 당신을 기다리는지 한눈에 볼 곳이 없죠.

Baton과 AI agent의 관계는 tmux와 shell의 관계와 같습니다. Baton은 **키보드만으로 조종하는 하나의 조종석**을
줍니다. 모든 agent를 담은 실시간 대시보드에서, 각 agent는 자신이 속한 작업별로 묶이고, 어느 것이든 키 하나
거리에 있습니다.

지휘봉은 당신 손에 있습니다. agent들이 연주하고, 당신이 지휘합니다. 🎼

![Baton 조종석 데모 — 대시보드 위의 패널들, 하나를 확대해 조작하기, 두 개를 하나의 작업 항목으로 묶기, conductor와 global shell 열기](assets/baton-demo.png)

_패널을 띄우고, 하나를 확대해 조작하고, 둘을 하나의 작업 항목으로 묶고, `C`로 conductor를, `H`로 global
shell을 불러 보세요 — 그리고 `?`는 언제나 그 자리에서 키를 알려줍니다._

_영상은 [`baton-demo.tape`](assets/baton-demo.tape)로 만들었습니다 — 재생성 절차는 해당 tape 파일의 헤더에
있습니다. 영상 속 conductor의 agent CLI는 대역([`demo-agent.sh`](assets/demo-agent.sh))이라 어느 머신에서도
같은 영상이 녹화됩니다. 그것이 socket으로 몰아가는 함대는 진짜입니다._

## 시작하기

Baton은 단일 정적 실행 파일입니다. macOS에서는 [Homebrew](https://brew.sh)로 가볍게 설치하세요.

```sh
brew install cmj0121/tap/baton
```

Linux에서는 한 줄이면 됩니다.

```sh
curl -fsSL https://raw.githubusercontent.com/cmj0121/baton/main/scripts/install.sh | sh
```

…또는 플랫폼을 가리지 않고 [Go](https://go.dev) 1.26+ 로 받을 수도 있습니다.

```sh
go install github.com/cmj0121/baton/cmd/baton@latest
```

…또는 clone 받은 소스에서 `make install`로 빌드하세요. 그다음 그냥 실행하면 됩니다.

```sh
baton
```

Baton은 백그라운드 서버를 띄우고 당신을 **대시보드** — 당신의 본진 — 에 내려놓습니다. 첫 1분은 이렇게
보내세요.

1. **`A`** 를 눌러 agent를 띄웁니다(작업 디렉터리를 고르게 됩니다).
2. **`enter`** 를 눌러 확대해 일하는 모습을 지켜보고, **`C-t d`** 로 대시보드에 돌아옵니다.
3. **`q`** 를 눌러 분리(detach)하고 자리를 떠나세요 — 모든 것은 계속 돌아갑니다. 언제든 `baton`으로 돌아오면
   됩니다.

길을 잃었나요? **`?`** 는 지금 있는 화면의 키를 언제나 보여줍니다.

## 개념

- **shell이 아니라 agent.** 작업의 단위는 돌보아야 할 창이 아니라, 실행 중인 agent입니다.
- **창이 아니라 대시보드.** 탭 더미가 아니라, 전부를 한 번에 보는 실시간 개요입니다.
- **헤드리스 코어, 교체 가능한 프런트엔드.** 두뇌는 백그라운드 데몬이고, 그것을 그려내는 얼굴은 갈아 끼울 수
  있습니다.

| 개념             | 무엇인가                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| **Panel**        | 하나의 라이브 터미널 — _agent_ 패널(agent CLI) 또는 _shell_ 패널.                                       |
| **Work item**    | 하나의 작업에 속하는, 이름이 붙은 패널 묶음.                                                            |
| **Task**         | agent에게 넘기는 지시서 — 생명주기 전반이 추적되며, 기다려야 한다면 큐에 넣고 스케줄링됩니다.           |
| **Conductor**    | 당신을 대신해 함대를 몰아주는 agent — socket 너머로 다른 패널을 띄우고, 묶고, 프롬프트를 보냅니다.      |
| **Global shell** | 서버가 `$HOME`에 하나만 쥐고 있는 순수 호스트 shell, 언제나 키 하나 거리 — 함대의 조종자가 아니라 본진. |

## 화면

Baton은 세 가지 화면으로 조종하며, 키 하나로 그 사이를 오갑니다.

- **대시보드(Dashboard)** — 관제탑. 모든 패널을 상태와 미리보기와 함께 보여주는 실시간 그리드(수가 많아지면
  트리로 바뀝니다). 여기서 이동하고, 패널을 띄우고 닫고, 작업 항목으로 묶습니다.
- **그룹(Group)** — 한 작업 항목의 실시간 분할 화면. 소속 패널들이 나란히 타일로 깔려 모두 동시에 스트리밍
  됩니다. 앞의 몇 개는 라이브 타일로 흐르고, 나머지는 하나의 **요약 타일**로 접혀 확대해 볼 수 있습니다. 몇
  개를 고정(pin)해 항상 켜 두거나, **`i`** 로 포커스된 패널을 그 자리에서 조작하거나, **`enter`** 로 그 안에
  들어가세요.
- **확대(Zoom)** — 패널 하나가 당신의 유일한 터미널이 됩니다. 키 입력은 곧바로 프로그램으로 가고, 리더 키
  **`C-t`** 가 동작을 취하거나 한 단계 물러나는 방법입니다.

## 키

키는 **모달(modal)** 입니다. 대시보드와 그룹에서는 각 동작이 키 하나이고, 확대나 상호작용 중에는 키 입력이
프로그램을 조작하므로 Baton의 동작은 리더 키 **`C-t`** 다음에 그 키를 누르는 형태가 됩니다. 현재 화면의
완전하고 재바인딩 가능한 목록은 **`?`** 로 보고, 키 맵 편집은 **`C-t k`** 로 하세요.

| 어디서      | 키                | 동작                                           |
| ----------- | ----------------- | ---------------------------------------------- |
| After `C-t` | `d` / `b`         | 대시보드로 이동 / 한 단계 뒤로                 |
|             | `[`               | 스크롤 모드로 진입                             |
|             | `R` / `S`         | 설정 다시 읽기 / 서버 강제 재시작              |
|             | `q`               | 분리(서버는 계속 실행)                         |
| Dashboard   | `hjkl` / arrows   | 커서 이동                                      |
|             | `enter`           | 선택 항목 열기 / 확대                          |
|             | `p` / `A` / `c`   | 새 shell / agent / 명령 선택 패널              |
|             | `.`               | 포커스된 패널의 디렉터리에 새 shell 패널       |
|             | `C`               | conductor 열기(함대를 몰아주는 agent)          |
|             | `H`               | global shell 열기(`$HOME`의 호스트 shell)      |
|             | `w` / `x`         | 선택 항목 닫기 / 종료된 것 정리                |
|             | `r`               | 포커스 아래의 종료된 패널 다시 실행            |
|             | `g` / `G` / `u`   | 표시 / 표시한 패널 묶기 / 묶음 해제            |
|             | `s` / `f` / `D`   | 선택 항목에 시그널 / 찾기 / diff               |
|             | `/`               | 모든 패널의 출력 검색(함대 전체 grep)          |
|             | `T` / `Q`         | 작업 배정 / 작업 큐 관리                       |
|             | `U`               | 사용량 푸터 전환: 끄기 / 청구 창 / 포커스 패널 |
|             | `K`               | 푸터의 키 입력 표시 토글                       |
| Group       | `tab`             | 다음 패널로 포커스                             |
|             | `+` / `-`         | 라이브 타일 늘리기 / 줄이기                    |
|             | `L`               | 타일 레이아웃 순환                             |
|             | `p` / `i`         | 포커스된 패널 고정 / 조작                      |
|             | `enter`           | 포커스된 패널 확대                             |
| Zoom        | 타이핑            | 프로그램을 직접 조작                           |
|             | `C-t f` / `C-t g` | 스크롤백 검색 / git 메뉴(agent)                |

화면별 완전한 키 참조와 각 화면 뒤의 설계는 **[docs/SPEC.md](SPEC.md)** 를 보세요.

## 기능

함대를 돌보는 동안 손이 갈 만한 모든 것이, 키 하나 거리에 있습니다.

- **시그널(Signals)** — `s` 는 선택 항목, 포커스된 타일, 또는 그룹 전체에 어떤 시그널이든 보냅니다. 선택기가
  흔한 것들을 나열하고, `o` 로 아무 이름이나 번호를 입력할 수 있습니다.
- **찾기, 검색, 복사** — `f` 는 제목이나 그룹으로 함대를 걸러냅니다. `/` 는 모든 패널의 출력을 한 번에 grep해
  결과를 패널별로 묶어 보여주고, `enter` 로 고른 것을 확대하면 매치된 지점에 바로 내려앉습니다. `C-t f` 는 한
  패널의 스크롤백을 정규식으로 검색합니다. 스크롤 모드(`C-t [`)는 OSC52로 선택·복사하므로 보조 실행 파일 없이
  SSH 너머에서도 동작합니다.
- **Diff** — `D`(확대 중에는 `C-t D`)는 해당 agent 패널의 워크트리 diff를 띄웁니다 — staged와 unstaged를 한
  번에, untracked 포함 — 마스터-디테일 오버레이로 보여줍니다.
- **Git** — `C-t g` 는 확대된 agent를 대상으로 git 메뉴를 엽니다: diff, log, status, stage, commit, push,
  branch, worktree. **[docs/GIT.md](GIT.md)** 를 보세요.
- **Conductor와 제어** — `C` 는 conductor를 엽니다. 당신을 대신해 함대를 몰아주는 agent입니다. socket 너머로
  — `baton ctl` 이나 `baton mcp` 도구를 통해 — 다른 패널을 띄우고, 묶고, 시그널을 보내고, 프롬프트를 던지며,
  자기 호스트를 망가뜨리지 못하도록 울타리가 쳐져 있습니다. 목표는 `$HOME/.baton/CONDUCTOR.md` 에서
  설정하세요. **[docs/CONTROL.md](CONTROL.md)** 를 보세요.
- **Global shell** — `H` 는 global shell을 엽니다. 서버가 `$HOME`에 쥐고 있는 단 하나의 순수 호스트 shell로,
  언제나 키 하나 거리에 있습니다. conductor와 마찬가지로 카드가 아니라 FLEET 제목의 표식으로 나타나고, 서버는
  딱 하나만 유지합니다 — 재시작 후에는 종료된 빈 자리로 남아 `r` 로 다시 실행할 수 있습니다. conductor와 달리
  아무것도 몰지 않습니다: 한정된 역할도, 관리되는 작업 공간도 없습니다. (떠다니는 **scratch** shell `C-t ~` 와는
  다릅니다. 그쪽은 일시적이라 분리하면 사라집니다.)
- **작업과 큐** — `T` 는 지시서를 한 agent에게 배정하거나(또는 작업 항목 전체에 퍼뜨리고), 카드에 기록해 두었다가
  agent가 준비되면 전달합니다. `Q` 는 서버가 소유한 스케줄러가 한가한 agent에게 흘려보내는 영속적인 백로그를
  관리합니다 — 바로 **당신 → conductor → 함대** 의 흐름입니다. `task.pre` Lua 훅은 지시서를 고쳐 쓰거나 거부할
  수 있고, `task.change` 는 그것을 지켜봅니다.
- **그룹과 요약** — `+` / `-` 로 몇 개의 멤버가 라이브 타일로 흐를지 조절하고, 나머지는 하나의 요약 타일로
  접힙니다. 고정된 멤버는 언제나 스트리밍됩니다. `L` 은 분할 화면의 **레이아웃** 을 순환합니다 — 균등 그리드,
  `main-vertical`, `main-horizontal`, `stack`, 또는 `TUI.yaml` 에 직접 정의한 그리드.
- **자원 상한** — 한 패널이 쓸 수 있는 CPU, 메모리, 프로세스 수에 상한을 걸고, 그 **프로세스 트리 전체** 를
  그 안에 묶어 둡니다. 폭주한 빌드가 머신을 통째로 끌고 가지 못하도록 말이죠. 함대 전체의 기본선과 agent별
  덮어쓰기는 설정 파일이나 `C-t P` 에서 지정하고, `C-t R` 로 실행 중인 함대에 적용합니다. Linux에서는 cgroup
  v2로 강제되며, 호스트가 강제할 수 없을 때는 패널이 솔직하게 알려줍니다. **[docs/LIMITS.md](LIMITS.md)** 를
  보세요.
- **외관** — `$HOME/.baton/TUI.yaml` 이 조종석을 다시 빚습니다: 색상 **테마** 와 그룹 분할의 **레이아웃** 을
  `C-t R` 로 핫 리로드합니다. **[docs/TUI.md](TUI.md)** 를 보세요.
- **사용량 푸터** — `U` 는 그날의 토큰 사용량과 비용(`⊙ 1.2M tok · ≈$12.34 API`)을 보여주는 푸터를 토글합니다.
  기본적으로 Claude Code 자체의 transcript를 읽고(Pro/Max 구독에서도 동작합니다), 키가 있으면 Anthropic Admin
  API를 씁니다. 이 비용은 API 환산값이지 구독 요금이 아닙니다. **[docs/USAGE.md](USAGE.md)** 를 보세요.
- **영속성과 재생성** — Baton은 재시작 너머로 자신의 함대를 기억합니다. 패널은 멈춰 있는 종료 상태의 빈 자리로
  돌아오고, `r` 이 보관된 명세대로 그것들을 다시 실행합니다.
- **다시 읽기** — `C-t R`(또는 데몬에 `SIGHUP`)은 함대를 재시작하지 않고 설정을 핫 리로드합니다.
- **마우스** — 터미널 자체의 선택 기능을 살려 두기 위해 기본은 꺼짐입니다. 키 맵에서 켜면 휠로 스크롤하고
  선택할 수 있습니다.
- **언어** — `?` 키 목록과 `C-t k` 키 맵은 영어 또는 繁體中文으로 읽힙니다. `settings.language` 를 설정하거나,
  키 맵에서 실시간으로 순환시키거나, 그냥 `$LANG` 이 정하게 두세요. **[docs/TUI.md](TUI.md#language)** 를
  보세요.

## 화면 보호기

자리를 떠나 그대로 두세요. 몇 분간 아무 조작이 없으면 — 또는 숨겨진 `C-t E` 를 누르면 — 조종석은 전체 화면
Matrix 디지털 비로 빠져들고, 한가운데 **BATON** 워드마크와 커다란 시계가 떠 있습니다. 순전히 프런트엔드만의
점령입니다. 서버로는 아무것도 보내지 않으며, 아무 키나 클릭이면 곧바로 원래 화면으로 돌아옵니다.

## 아키텍처

헤드리스 **baton server**(백그라운드 데몬)가 모든 상태와 모든 터미널을 소유합니다. 교체 가능한 프런트엔드는
단 하나의 Unix 도메인 socket으로 붙습니다 — 명령은 위로, 이벤트는 아래로 — 그래서 분리했다가 다시 붙어도 아무
것도 잃지 않습니다.

전체 다이어그램과 상호작용 모델은 **[docs/SPEC.md](SPEC.md)** 를 보세요.

## 플러그인

Lua 파일 하나(`$HOME/.baton/plug-in.lua`)면 Baton을 당신의 워크플로에 맞게 다시 빚을 수 있습니다: 생명주기
이벤트에 반응하고(agent가 당신을 필요로 할 때 알려주기, 하나가 끝나면 다음 단계로 이어 붙이기), 함대를 몰고,
자신만의 명령을 추가하고, 설정을 지정하는 것까지 — 전부 하나의 `baton` 객체를 통해서.
**[docs/PLUGIN.md](PLUGIN.md)** 를 보세요.
